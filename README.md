# MSc Dissertation Code

This repository contains the Python code used for my MSc dissertation.

## Notebooks

- `01_Data_Import_Preparation.ipynb` – data preparation and preprocessing
- `02_EDA.ipynb` – exploratory data analysis
- `03_Synthetic_Data.ipynb` – synthetic-data validation
- `04_Empirical_Results.ipynb` – final results
